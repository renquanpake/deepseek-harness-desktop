# DeepSeek Harness 桌面增强发行版

> 专为国内开发者与 Windows 平台深度调优的 DeepSeek Harness (DSH) 原生桌面客户端。
> 开箱即用 · 壳核解耦秒级热更 · 独立多分支工作台 · 零配置畅享国内高速网络。

---

## 🚀 30 秒极速上手指南

### 方式一：普通用户（小白推荐，直接运行）
1. 从 Releases 下载 `DeepSeek-Harness-Desktop-Setup.exe` 安装包（或下载 `Portable` 便携免安装版）。
2. 双击打开，软件将自动就绪（**无需安装 Node.js、无需配置 npm/pnpm 环境变量**）。
3. 在界面中配置您的 DeepSeek API Key，即可开启流畅的 AI 协作。

### 方式二：开发者（源码一键运行）
本项目提供极简脚本，无需在命令行敲繁琐命令：
- **一键运行**：在项目根目录双击 `一键启动.bat`，脚本将自动配置国内镜像、补全依赖并拉起桌面端。
- **一键打包**：双击 `一键打包.bat`，全自动生成 Windows 安装包与绿色便携版（产物输出至 `dist/` 目录）。

## 🌟 核心特色功能（为什么不用纯 Web 套壳？）

* **⚡ 国内双轨秒级热更**：
  * **内核更新**：走阿里云国内镜像（npmmirror），秒级热更新，无需重新下载几百兆完整安装包。
  * **外壳升级**：集成国内高速 CDN 加速拉取，静默安装且自动自愈，彻底告别外网下载龟速。
* **🛡️ 端口防冲突与崩溃自愈**：
  * 启动时自动探测端口，若 `3080` 被占用自动顺延切换（3081、3082...），绝不因为端口冲突报错崩溃。
  * 内置健康看门狗，若新内核出现故障，自动平滑隔离并回退至出厂保底内核，杜绝无限重启死循环。
* **🌿 独立工作区分支 (Git Worktree)**：
  * 支持针对当前项目秒级建立独立的 Git 分支沙箱窗口，多任务并行修改不打架、不污染主分支。
* **🔔 后台指令审批原生提醒**：
  * 当窗口最小化或切到后台时，若智能体需要用户审批执行命令，自动弹出 Windows 桌面原生系统通知。
* **🖼️ 剪贴板截图一键投喂**：
  * 按下 `Alt + Shift + V`，自动将剪贴板中的最新截图存盘并注入至对话框，跨平台与 WSL2 自动适配路径。
* **🔋 智能低功耗节流**：
  * 窗口失焦或最小化时自动将前端渲染刷新率限制至低频，消除传统 Web 套壳空载偷跑 CPU 的顽疾。

## 🛠️ 手动开发与构建命令

```bash
# 1. 安装项目依赖（推荐使用国内镜像）
npm install --registry=https://registry.npmmirror.com

# 2. 准备出厂内置运行时与插件
npm run runtime:prepare

# 3. 启动开发模式
npm start

# 4. 执行全量测试（包含 44 项严密自愈测试）
npm test

# 5. 打包生成 Windows 安装包
npm run dist
```
